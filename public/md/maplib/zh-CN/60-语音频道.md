<h1 id="语音频道" data-toc-id="语音频道">语音频道</h1>
<p>MapLib 可管理 Simple Voice Chat 的语音分组，并从服务端强制禁止指定玩家发送语音，适合阵营频道或有阶段性发言规则的地图。</p>
<h2 id="前置要求" data-toc-id="前置要求">前置要求</h2>
<p>先在客户端与服务器安装 <a href="https://www.curseforge.com/minecraft/mc-mods/simple-voice-chat" target="_blank" rel="noopener noreferrer nofollow">Simple Voice Chat</a>，使用支持 API 2.6.0+ 的版本，并确认玩家已经能够正常连接语音服务。MapLib 不包含语音模组本体；未安装时不会注册 <code>ml:voice</code> 指令。</p>
<h2 id="创建与分配频道" data-toc-id="创建与分配频道">创建与分配频道</h2>
<pre language="plaintext" isclosed="false"><code class="language-plaintext">/ml:voice create explorers
/ml:voice join explorers @a[tag=explorer]
/ml:voice remove explorers @a[tag=explorer]</code></pre>
<table data-type="custom-table" data-with-header-row="true">
  <tbody>
    <tr><th>指令</th><th>作用</th></tr>
    <tr><td>ml:voice create &lt;channel&gt;</td><td>创建命名频道，重复名称会提示已存在</td></tr>
    <tr><td>ml:voice join &lt;channel&gt; &lt;players&gt;</td><td>将在线玩家加入该频道；需要频道已创建且玩家语音可用</td></tr>
    <tr><td>ml:voice remove &lt;channel&gt; &lt;players&gt;</td><td>让目标玩家退出该频道，并非删除频道</td></tr>
    <tr><td>ml:voice mute &lt;players&gt; &lt;true|false&gt;</td><td>设置或解除服务端强制禁言</td></tr>
  </tbody>
</table>
<p>频道名使用不含空格的标识。示例中的玩家需先有 <code>explorer</code> 标签。频道创建、加入或退出失败时，检查反馈中的频道存在状态及玩家语音连接状态。</p>
<h2 id="服务端强制禁言" data-toc-id="服务端强制禁言">服务端强制禁言</h2>
<pre language="plaintext" isclosed="false"><code class="language-plaintext">/ml:voice mute @a[tag=!wolf] true
/ml:voice mute @a false</code></pre>
<p><code>true</code> 禁止目标玩家发送语音，<code>false</code> 解除强制限制。禁言覆盖频道、距离语音与悄悄话，不影响收听；切换频道、调整客户端 GUI 或断线重连都不会解除。</p>
<p>可对尚未连接语音服务的在线玩家预先设置。状态在本次语音服务运行期间保留，语音服务停止后清除，不写入世界存档。需要每局执行规则时，在地图流程中重新设置，并在结束阶段显式解除。</p>
<h2 id="常见问题" data-toc-id="常见问题">常见问题</h2>
<h3 id="找不到-mlvoice" data-toc-id="找不到-mlvoice">找不到 ml:voice</h3>
<p>确认服务端安装的是 Simple Voice Chat 本体，模组 ID 为 <code>voicechat</code>；只下载 API 或只给客户端安装无法提供服务端语音频道。</p>
<h3 id="加入频道失败" data-toc-id="加入频道失败">加入频道失败</h3>
<p>先创建对应频道，再检查所选玩家是否在线并已连接语音服务。返回“语音 API 不可用”时，先处理 Simple Voice Chat 的服务与网络配置。</p>
