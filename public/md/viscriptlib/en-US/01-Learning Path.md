<h1 id="editor-learning-path" data-toc-id="editor-learning-path">Editor learning path</h1>
<p>Learn manual saving first, arrange the workspace, then try AI assistance. Keep track of three separate states: the current in-memory project, the saved local file, and the content published to a server.</p>
<h2 id="read-by-goal" data-toc-id="read-by-goal">Read by goal</h2>

<tr><td>Use a series editor for the first time</td><td>Editor basics → Common components</td><td>Save a file that you can reopen and continue editing.</td></tr>
<tr><td>Keep the editor next to the game</td><td>Desktop windows and layout</td><td>Detach, resize and dock the editor without changing its project.</td></tr>
<tr><td>Connect your model service</td><td>Connection and edit preferences → Chat and images</td><td>Receive a reply and understand the enabled editing capabilities.</td></tr>
<tr><td>Ask AI to edit content</td><td>Preview apply and undo → Editor examples and limits</td><td>Inspect the real draft, apply it, undo and redo the turn, then save.</td></tr>
<tr><td>Build an addon editor</td><td>Developer integration</td><td>Define domain validation, previews, history and a separate trusted publication path.</td></tr>

<h2 id="try-one-complete-workflow" data-toc-id="try-one-complete-workflow">Try one complete workflow</h2>
<div currentstep="0" data-type="steps">
<div data-type="step-item"><div data-type="admonition-title">Save a practice file</div><div data-type="admonition-content"><p>Open the editor through the owning mod, create a small project and save it under a new name.</p>
</div></div>
<div data-type="step-item"><div data-type="admonition-title">Arrange the workspace</div><div data-type="admonition-content"><p>Follow <a href="?file=&quot;Editor.Desktop Windows and Layout&quot;">Desktop Windows and Layout</a> to detach the editor, choose a readable scale and return it to the game.</p>
</div></div>
<div data-type="step-item"><div data-type="admonition-title">Set up AI</div><div data-type="admonition-content"><p>Follow <a href="?file=&quot;AI.Connection and Edit Preferences&quot;">Connection and Edit Preferences</a>, apply your connection settings, then open chat from the AI menu.</p>
</div></div>
<div data-type="step-item"><div data-type="admonition-title">Make a small change</div><div data-type="admonition-content"><p>Use an <a href="?file=&quot;AI.Editor Examples and Limits&quot;">example prompt</a> that first reads the project, then requests a small, checkable edit.</p>
</div></div>
<div data-type="step-item"><div data-type="admonition-title">Apply, undo and save</div><div data-type="admonition-content"><p>Follow <a href="?file=&quot;AI.Preview Apply and Undo&quot;">Preview Apply and Undo</a> to inspect and apply the draft. Undo and redo the turn, then save through the normal file menu. Publish separately if required.</p>
</div></div>
</div>
