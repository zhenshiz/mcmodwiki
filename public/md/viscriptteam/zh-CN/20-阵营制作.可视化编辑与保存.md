<h1 id="可视化阵营编辑与保存" data-toc-id="可视化阵营编辑与保存">可视化阵营编辑与保存</h1>
<p><a href="?file=&quot;学习路线&quot;">学习路线与视频目录</a> · <a href="?file=&quot;排错与数据维护&quot;">排错与数据维护</a></p>
<p>场景：创建 ID 为 wiki_guards 的守卫阵营，显示名改为“巡逻守卫”，再保存。阵营编辑器和阵营后台命令需要权限等级 2。</p>
<pre language="plaintext" isclosed="false"><code class="language-plaintext">/viscript_team faction
/viscript_team faction open</code></pre>
<ol><li><p>点击“创建阵营”，输入固定 ID 和可选显示名称。编辑器 ID 为 1–64 个英文字母、数字、下划线、短横线或点；首尾空白去除并转小写。</p>
</li><li><p>创建后从左侧选中阵营，在右侧修改显示名称、颜色、友伤、主动攻击和敌对阵营列表。修改已有名称时先清除旧名称再输入。固定 ID 不能改名，命令仍使用这个 ID。</p>
</li><li><p>点击“保存阵营设置”，看到成功通知后再切换阵营。修改表单本身不等于已经保存。</p>
</li></ol>

<h2 id="每个设置如何影响玩法" data-toc-id="每个设置如何影响玩法">每个设置如何影响玩法</h2>
<table data-type="custom-table" data-with-header-row="true"><tbody><tr><th>设置</th><th>实际作用</th><th>容易混淆的地方</th></tr><tr><td>显示名称</td><td>编辑器与联动显示使用的名称，最多 64 字符。</td><td>不是命令中的固定 ID；留空使用 ID。</td></tr><tr><td>阵营颜色</td><td>地图界面、脚本或联动读取的代表色。</td><td>不覆盖实体名牌的友好绿、中立黄、敌对红。</td></tr><tr><td>允许阵营友伤</td><td>允许同阵营实体及对该阵营友好的玩家之间受到相应伤害。</td><td>与玩家队伍友伤独立。</td></tr><tr><td>主动攻击敌对阵营</td><td>允许属于本阵营的生物寻找敌对列表中的阵营实体。</td><td>不代替玩家声望判断，也不赋予所有实体攻击技能。</td></tr><tr><td>敌对阵营 ID 列表</td><td>点加号添加，搜索并选择已有的其他阵营 ID；不允许自身或重复项。</td><td>关系单向；双方敌对要分别保存两边。</td></tr></tbody></table>
<h2 id="编辑器以外还要做什么" data-toc-id="编辑器以外还要做什么">编辑器以外还要做什么</h2>
<p>实体归属、玩家声望及声望阈值不在这个表单中。实体归属和玩家声望用命令或服务端脚本管理；全局配置提供新建阵营的默认阈值。</p>
