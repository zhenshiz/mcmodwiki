<h1 id="ai-connection-and-edit-preferences" data-toc-id="ai-connection-and-edit-preferences">AI connection and edit preferences</h1>
<p>Configure a model service you can access before opening chat. VSL does not bundle a model or account. Participating VSL editors on the same client share these preferences.</p>
<h2 id="connect-for-the-first-time" data-toc-id="connect-for-the-first-time">Connect for the first time</h2>
<div currentstep="0" data-type="steps">
<div data-type="step-item"><div data-type="admonition-title">Open AI settings</div><div data-type="admonition-content"><p>Choose File → Settings in a VSL editor, expand the settings categories and select AI. The top-level AI menu opens chat; connection settings live here.</p>
</div></div>
<div data-type="step-item"><div data-type="admonition-title">Enable and configure</div><div data-type="admonition-content"><p>Enable AI, choose the protocol offered by your service, then enter its endpoint, exact model ID and required API key.</p>
</div></div>
<div data-type="step-item"><div data-type="admonition-title">Choose editing preferences</div><div data-type="admonition-content"><p>Keep confirmation enabled for your first edits. Questions do not require project editing; enable it when you want the domain adapter to generate changes.</p>
</div></div>
<div data-type="step-item"><div data-type="admonition-title">Apply the preferences</div><div data-type="admonition-content"><p>Apply saves without closing; Confirm saves and closes. Saving settings does not send a model request.</p>
</div></div>
<div data-type="step-item"><div data-type="admonition-title">Send a check message</div><div data-type="admonition-content"><p>Open chat from the AI menu and ask it to describe the current editor’s supported operations without modifying the project. Try a small edit after receiving a reply.</p>
</div></div>
</div>

<h2 id="apply-confirm-and-cancel" data-toc-id="apply-confirm-and-cancel">Apply, confirm and cancel</h2>
<p>Apply saves the current preferences and keeps the dialog open. Confirm saves and closes. Cancel restores changes since the last Apply, so it does not undo values already saved with Apply.</p>
<h2 id="local-storage" data-toc-id="local-storage">Local storage</h2>
<p>Settings are stored in <code>config/ldlib2/editor.json</code> under <code>viscript_lib:ai</code> in the current game instance. The key is excluded from project export/upload but remains in this local settings file. Remove it before sharing diagnostic material. Chat and image attachments are not saved there.</p>
<div type="info" data-type="admonition" data-admo-type="info"><div data-type="admonition-title">Client preferences are not server authorization</div><div data-type="admonition-content"><p>Applying a draft changes the current editor project. Saving, exporting and uploading remain separate operations subject to the owning mod’s normal server permissions.</p>
