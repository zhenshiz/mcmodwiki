<h1 id="路线导航" data-toc-id="路线导航">路线导航</h1>
<p>MapLib 在客户端计算可通行路线，以红色起点、黄色中段、绿色终点的导引线显示在世界中。路线按玩家分别显示，并保留墙体遮挡；玩家仍自行移动。</p>
<h2 id="固定目标与实体目标" data-toc-id="固定目标与实体目标">固定目标与实体目标</h2>
<pre language="plaintext" isclosed="false"><code class="language-plaintext">/ml:pathfind to 100 64 100
/ml:pathfind to 100 64 100 @a
/ml:pathfind follow @e[tag=guide,limit=1] @a
/ml:pathfind from entity @s to 100 64 100
/ml:pathfind from block 0 64 0 to 100 64 100 @a
/ml:pathfind from block 0 64 0 follow @e[tag=guide,limit=1] @a
/ml:pathfind clear @a</code></pre>
<p><code>to</code> 使用目标脚部方块坐标，<code>follow</code> 使用单个实体。<code>from entity</code> 和 <code>from block</code> 可指定起点，两者都支持后接 <code>to</code> 或 <code>follow</code>。省略末尾玩家选择器时显示给执行玩家；控制台和命令方块必须填写玩家选择器。实体示例需先准备带 <code>guide</code> 标签的目标。</p>
<h2 id="更新与清理" data-toc-id="更新与清理">更新与清理</h2>
<p>新请求替换原有手动路线，<code>clear</code> 取消计算并清除显示；退出世界或切换维度时清理。实体起点移动约 2 格、实体终点移动约 1 格后更新，静止时每 5 秒重新检查地形。实体端点需要在客户端可见，才能持续跟踪。</p>

<p>跳跃线段连接起跳点与落地点，不代表空中的运动轨迹。寻路器的可通行范围不等同于所有原版跑酷技巧。</p>
<h2 id="viscriptquests-位置任务联动" data-toc-id="viscriptquests-位置任务联动">ViScriptQuests 位置任务联动</h2>
<p>同时安装 ViScriptQuests 后，位置任务节点中会增加 <strong>显示 MapLib 寻路线</strong> 选项，内部字段为 <code>maplib_path</code>，默认关闭。先按 ViScriptQuests 的流程配置位置任务与导航目标，再开启该选项并保存、应用任务。</p>
<p>玩家获得对应的任务导航标记后，MapLib 会选取当前维度中尚未到达、距离最近且启用了寻路线的目标。到达标记的到达半径、任务标记消失或切换世界后，相应任务路线会清理或改选。已有任务不会因安装 MapLib 而全部自动开启。</p>
<p>手动指令或 API 创建的路线优先显示，任务联动不会覆盖它。使用 <code>ml:pathfind clear</code> 清除后，仍处于追踪状态的任务目标可以再次显示联动路线；要停用任务路线，应关闭任务的寻路线选项或结束对应追踪。</p>
<p>任务配置流程可继续阅读 <a href="/wiki/ViScriptQuests" target="_blank" rel="noopener noreferrer nofollow">ViScriptQuests 文档</a>。联动路线仍受已加载地形和寻路范围限制。</p>
<h2 id="常见问题" data-toc-id="常见问题">常见问题</h2>
<h3 id="提示仅显示部分路线" data-toc-id="提示仅显示部分路线">提示仅显示部分路线</h3>
<p>远处区块尚未加载或搜索达到时限时，会只显示已找到的一段。向目标靠近加载更多地形后，路线会重新计算。</p>
<h3 id="完全没有可通行路线" data-toc-id="完全没有可通行路线">完全没有可通行路线</h3>
<p>确认起点已加载、终点是脚部可站立位置、维度一致、距离在范围内。路线不会假设可以拆墙或搭桥；跑酷路线还需满足冲刺与跳跃条件。</p>
<h3 id="任务有目标标记但没有导引线" data-toc-id="任务有目标标记但没有导引线">任务有目标标记但没有导引线</h3>
<p>检查位置节点是否开启“显示 MapLib 寻路线”、修改是否已应用、玩家是否处于目标维度，以及目标是否已经在到达半径内。</p>
