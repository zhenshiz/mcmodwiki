  <li>
    <p>Newly added fields for dialogue text configuration:</p>
    <ul>
      <li>
        <p><code>bgm</code>: Used to control background music playback</p>
        <ul>
          <li>
            <p>If the value is valid, as long as the player is in the dialog interface, the sound effect will play repeatedly</p>
          </li>
          <li>
            <p>In consecutive dialogues, if the field value is the same, the background music will not restart</p>
          </li>
          <li>
            <p>Filling in an empty string will stop the background music (I don't want to add a field like stop BGM just for the BGM).</p>
          </li>
          <li>
            <p>If you don't write this field (i.e., in the case of null), there will be no action (meaning you can only write this field when you need to play or stop background music)</p>
          </li>
        </ul>
      </li>
      <li>
        <p>
          <code>stayTick</code>: Players are forced to stay in the dialogue for a long time. If the specified duration is not reached, the player cannot jump to the next dialogue line (default value is 0; if the number is negative, the player cannot jump regardless of how long it takes and does not affect the selection process).
        </p>
      </li>
    </ul>
  </li>
  <li>
    <p>Fixed a bug where it could not properly check if the sound effect was playing</p>
  </li>
</ul>
