<h1 id="指令与配置" data-toc-id="指令与配置">指令与配置</h1>
<p>本页供整合包作者和服务器管理员使用，包含全部内置指令、配置文件、FTB 侧边栏入口和安全更新流程。普通玩家的操作请参阅<a href="?file=&quot;11-快速开始.玩家购买指南.md&quot;">玩家购买指南</a>。</p>
<h2 id="权限概览" data-toc-id="权限概览">权限概览</h2>
<p><code>/viscript_shop</code> 根指令需要权限等级 2；其中编辑器需要权限等级 4。打开商店、打开编辑器和修改自己阶段的子指令只能由玩家实体执行，不能直接在服务端控制台执行。</p>
<div type="warning" data-type="admonition" data-admo-type="warning">
  <div data-type="admonition-title">不要向普通玩家开放整个根指令</div>
  <div data-type="admonition-content">
    <p>根指令还包含重载、库存、货币和阶段管理能力。若要给玩家一个商店入口，应使用 FTB Library 侧边栏按钮、任务奖励执行的固定指令或经过严格限定的权限规则。</p>
  </div>
</div>
<h2 id="商店与编辑器指令" data-toc-id="商店与编辑器指令">商店与编辑器指令</h2>
<table data-type="custom-table" data-with-header-row="true" style="min-width: 100px;">
  <tbody>
    <tr>
      <th>指令</th>
      <th>作用</th>
      <th>重要说明</th>
    </tr>
    <tr>
      <td>/viscript_shop editor [shop]</td>
      <td>打开空编辑器，或载入指定服务端商店</td>
      <td>需要等级 4；只能由玩家执行</td>
    </tr>
    <tr>
      <td>/viscript_shop open</td>
      <td>打开快捷商店选择界面</td>
      <td>只列出已允许快捷打开的商店</td>
    </tr>
    <tr>
      <td>/viscript_shop open &lt;shop&gt; [categoryId] [merchantId]</td>
      <td>打开指定商店，可直达分类和商品</td>
      <td>路径不含 .shop 后缀；只能由玩家执行</td>
    </tr>
    <tr>
      <td>/viscript_shop setQuickOpening &lt;shop&gt; &lt;true|false&gt;</td>
      <td>修改商店是否出现在快捷选择器</td>
      <td>修改当前世界中已加载的商店数据</td>
    </tr>
    <tr>
      <td>/viscript_shop reload [shop]</td>
      <td>重载全部商店或指定商店</td>
      <td>会清除对应运行时库存</td>
    </tr>
  </tbody>
</table>
<pre language="plaintext" isclosed="false"><code class="language-plaintext">/viscript_shop open village_market
/viscript_shop open village_market ores
/viscript_shop open village_market ores iron_ingot
/viscript_shop setQuickOpening village_market true
/viscript_shop reload village_market</code></pre>
<p>如果文件位于 <code>ldlib2/assets/viscript_shop/shop/events/summer.shop</code>，商店路径就是 <code>events/summer</code>。输入指令时可利用自动补全检查路径、分类 ID 和商品 ID。</p>
<h2 id="库存和删除指令" data-toc-id="库存和删除指令">库存和删除指令</h2>
<table data-type="custom-table" data-with-header-row="true" style="min-width: 100px;">
  <tbody>
    <tr>
      <th>指令</th>
      <th>作用</th>
    </tr>
    <tr>
      <td>/viscript_shop setStock &lt;shop&gt; &lt;categoryId&gt; &lt;merchantId&gt; &lt;stock&gt;</td>
      <td>立即修改指定商品在当前世界中的库存</td>
    </tr>
    <tr>
      <td>/viscript_shop addStock &lt;shop&gt; &lt;categoryId&gt; &lt;merchantId&gt; &lt;amount&gt;</td>
      <td>在指定商品当前剩余库存的基础上增加正整数数量</td>
    </tr>
    <tr>
      <td>/viscript_shop remove &lt;shop&gt; &lt;categoryId&gt; &lt;merchantId&gt;</td>
      <td>从当前世界中已加载的商店数据移除指定商品</td>
    </tr>
  </tbody>
</table>
<pre language="plaintext" isclosed="false"><code class="language-plaintext">/viscript_shop setStock village_market ores iron_ingot 500
/viscript_shop addStock village_market ores iron_ingot 100
/viscript_shop setStock village_market ores weekly_crate 0
/viscript_shop remove village_market ores retired_offer</code></pre>
<p><code>addStock</code> 会保留商品已经售出的数量，只给当前剩余库存补充指定数量。在共享库存模式下会增加全局剩余库存；在玩家独立库存模式下会增加所有已建立的玩家剩余库存，并同步提高尚未建立记录的基准库存。无限库存保持无限，有限库存最高为 2147483647。</p>
<p>这些指令不会改写磁盘上的 <code>.shop</code> 文件。之后重载商店时，商品和初始库存可能从文件恢复。需要永久修改时，应同时更新源文件并重新上传。</p>
<h2 id="阶段指令" data-toc-id="阶段指令">阶段指令</h2>
<pre language="plaintext" isclosed="false"><code class="language-plaintext">/viscript_shop stage add &lt;flag&gt;
/viscript_shop stage remove &lt;flag&gt;</code></pre>
<p>这两条指令只修改执行者本人。管理员要修改其他玩家时，可以让目标玩家执行固定命令，或借助原版 <code>execute as</code>：</p>
<pre language="plaintext" isclosed="false"><code class="language-plaintext">/execute as Steve run viscript_shop stage add chapter_2</code></pre>
<p>阶段标识区分具体文本，建议统一使用小写字母、数字和下划线，例如 <code>chapter_2</code>、<code>reputation_mage</code>。完整配置方法见<a href="?file=&quot;30-进阶系统.库存与阶段.md&quot;">库存与阶段</a>。</p>

<h2 id="公共配置文件" data-toc-id="公共配置文件">公共配置文件</h2>
<p>公共配置位于 <code>config/viscript_shop_config.toml</code> 的 <code>[config]</code> 段，由服务端决定。部分联动配置只会在对应模组已安装时生成。</p>
<table data-type="custom-table" data-with-header-row="true" style="min-width: 100px;">
  <tbody>
    <tr>
      <th>配置键</th>
      <th>默认值</th>
      <th>用途</th>
    </tr>
    <tr>
      <td>showFtbLibraryButton</td>
      <td>false</td>
      <td>安装 FTB Library 后，是否显示商店侧边栏按钮</td>
    </tr>
    <tr>
      <td>ftbDefaultShop</td>
      <td>空字符串</td>
      <td>FTB 按钮直达的商店路径；留空则打开商店选择器</td>
    </tr>
    <tr>
      <td>isReplaceMoneyToMagicCoin</td>
      <td>false</td>
      <td>安装 Magic Coins 后，是否用其余额替换本模组虚拟货币</td>
    </tr>
    <tr>
      <td>enableLegacyDataMigration</td>
      <td>true</td>
      <td>是否迁移旧版 .shop 文件；确认全部更新后可关闭以减少迁移开销</td>
    </tr>
    <tr>
      <td>maxShopUiGiveItemsPerPurchase</td>
      <td>-1</td>
      <td>商店界面单次购买最多发放多少个物品；-1 不限制</td>
    </tr>
    <tr>
      <td>isPersonalStock</td>
      <td>false</td>
      <td>false 为全服共享库存，true 为每位玩家独立库存</td>
    </tr>
  </tbody>
</table>
<pre language="toml" isclosed="false"><code class="language-toml">[config]
showFtbLibraryButton = true
ftbDefaultShop = "village_market"
enableLegacyDataMigration = true
maxShopUiGiveItemsPerPurchase = 4096
isPersonalStock = false</code></pre>
<p><code>ftbDefaultShop</code> 只填写 <code>/viscript_shop open</code> 后面的商店路径，不要填写指令本身，也不要加 <code>.shop</code>。路径为空时正常显示选择界面；路径无效时会向玩家显示错误并回退到选择界面。</p>
<h2 id="客户端主题配置" data-toc-id="客户端主题配置">客户端主题配置</h2>
<p>客户端配置位于 <code>config/viscript_shop_client.toml</code> 的 <code>[client]</code> 段，每位玩家可以独立选择。主题会应用于主商店、快捷商店选择器、成功提示等界面。</p>
<table data-type="custom-table" data-with-header-row="true" style="min-width: 100px;">
  <tbody>
    <tr>
      <th>shopUiTheme 值</th>
      <th>界面主题</th>
    </tr>
    <tr>
      <td>GLASS_DARK</td>
      <td>深色玻璃，默认主题</td>
    </tr>
    <tr>
      <td>GRAY_CAT_WORKSHOP</td>
      <td>灰猫工坊</td>
    </tr>
  </tbody>
</table>
<pre language="toml" isclosed="false"><code class="language-toml">[client]
shopUiTheme = "GLASS_DARK"</code></pre>
<p>修改主题后关闭并重新打开相关界面，以便所有控件按新主题重新创建。</p>
<h2 id="ftb-侧边栏入口教程" data-toc-id="ftb-侧边栏入口教程">FTB 侧边栏入口教程</h2>
<div currentstep="0" data-type="steps">
  <div data-type="step-item">
    <div data-type="admonition-title">安装 FTB Library</div>
    <div data-type="admonition-content">
      <p>确保客户端和服务端都安装了与当前 Minecraft 版本匹配的 FTB Library。</p>
    </div>
  </div>
  <div data-type="step-item">
    <div data-type="admonition-title">启用按钮</div>
    <div data-type="admonition-content">
      <p>在公共配置中把 <code>showFtbLibraryButton</code> 改为 <code>true</code>。</p>
    </div>
  </div>
  <div data-type="step-item">
    <div data-type="admonition-title">选择打开方式</div>
    <div data-type="admonition-content">
      <p><code>ftbDefaultShop</code> 留空时显示快捷选择器；填写 <code>village_market</code> 等路径时按钮直接打开该商店。</p>
    </div>
  </div>
  <div data-type="step-item">
    <div data-type="admonition-title">验证快捷列表</div>
    <div data-type="admonition-content">
      <p>如果使用选择器，确认需要展示的商店已在编辑器中启用“允许快捷打开”，或使用 <code>setQuickOpening</code> 指令开启。</p>
    </div>
  </div>
</div>
<h2 id="安全更新流程" data-toc-id="安全更新流程">安全更新流程</h2>
<div currentstep="0" data-type="steps">
  <div data-type="step-item">
    <div data-type="admonition-title">备份文件和世界</div>
    <div data-type="admonition-content">
      <p>备份 <code>ldlib2/assets/viscript_shop/shop</code> 以及世界存档。当前运行库存位于世界数据中，因此两者都要保留。</p>
    </div>
  </div>
  <div data-type="step-item">
    <div data-type="admonition-title">在副本中编辑</div>
    <div data-type="admonition-content">
      <p>不要让多名管理员同时覆盖同一商店。通过 Git 或清晰的文件命名保留发布前版本。</p>
    </div>
  </div>
  <div data-type="step-item">
    <div data-type="admonition-title">决定是否保留库存</div>
    <div data-type="admonition-content">
      <p>需要保留运营库存时，上传前关闭编辑器中的“上传后自动重载商店”；确实要按文件库存重置时再执行重载。</p>
    </div>
  </div>
  <div data-type="step-item">
    <div data-type="admonition-title">用普通账号验收</div>
    <div data-type="admonition-content">
      <p>检查阶段锁、折扣、库存、外部容器、发放上限和成交指令。购买后核对余额、物品和服务端日志。</p>
    </div>
  </div>
</div>
