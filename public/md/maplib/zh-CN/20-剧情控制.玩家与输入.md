<h1 id="玩家与输入" data-toc-id="玩家与输入">玩家与输入</h1>
<p>本页的玩家外观、姿势、按键和 HUD 指令默认作用于执行者。要控制其他玩家，请用 <code>execute as &lt;玩家&gt; at @s run ...</code>；实体发光指令自带观察者选择器。</p>
<h2 id="显示名与外观" data-toc-id="显示名与外观">显示名与外观</h2>
<pre language="plaintext" isclosed="false"><code class="language-plaintext">/ml:player name &quot;冒险者&quot;
/ml:player name
/ml:player skin &quot;Notch&quot;
/ml:player skin
/ml:player cape</code></pre>
<p><code>name</code> 设置显示名，省略值恢复原名称，不修改账号身份。<code>skin</code> 和 <code>cape</code> 接受玩家名称或资源位置，含 <code>:</code> 时按资源贴图解析；省略值重置。资源位置请加双引号，例如 <code>"demo:textures/entity/hero.png"</code>，并将对应文件放入客户端资源包的 <code>assets/demo/textures/entity/hero.png</code>。玩家名称方式需要客户端能够获取对应账号的皮肤资料。</p>
<p>名称、皮肤、披风与强制姿势随玩家数据保存，并在死亡后保留。剧情结束时应主动恢复需要撤销的设置。</p>
<h2 id="强制姿势与多段跳" data-toc-id="强制姿势与多段跳">强制姿势与多段跳</h2>
<pre language="plaintext" isclosed="false"><code class="language-plaintext">/ml:pose standing
/ml:pose swimming
/ml:pose
/attribute @s map_lib:multi_jump base set 2
/attribute @s map_lib:multi_jump base set 1</code></pre>
<p><code>ml:pose</code> 的值可用 Tab 查看原版姿势枚举。<code>standing</code> 会持续锁定站立姿态和眼高；不带参数执行 <code>ml:pose</code> 才是解除强制姿势。若蹲下时第一人称高度不变，先执行解除指令。</p>
<p><code>map_lib:multi_jump</code> 控制允许的总跳跃次数，默认 1，设为 2 可再进行一次空中跳跃；取整数部分，范围为 1～2048。在生存或冒险模式下，起跳后松开再按跳跃键触发；创造与旁观模式不启用此逻辑。</p>
<h2 id="锁定与恢复输入" data-toc-id="锁定与恢复输入">锁定与恢复输入</h2>
<pre language="plaintext" isclosed="false"><code class="language-plaintext">/ml:input lock movement true
/ml:input lock rotation true
/ml:input lock movement false
/ml:input lock rotation false
/execute as @a at @s run ml:input simulate forward 20</code></pre>
<p>语法为 <code>ml:input lock &lt;permission&gt; &lt;true|false&gt;</code>。<code>true</code> 添加该项锁，<code>false</code> 移除该项锁。锁具有父子关系：锁住父项后，单独解锁子项不会恢复输入。</p>
<table data-type="custom-table" data-with-header-row="true">
  <tbody>
    <tr><th>权限</th><th>包含内容</th></tr>
    <tr><td>all</td><td>全部输入的父项</td></tr>
    <tr><td>movement</td><td>lateral_move、jumping、shift_key_down、sprinting</td></tr>
    <tr><td>lateral_move</td><td>up、down、left、right（前后左右）</td></tr>
    <tr><td>rotation</td><td>rotation_horizontal、rotation_vertical</td></tr>
    <tr><td>mouse</td><td>mouse_attack、mouse_use、mouse_pick_item</td></tr>
    <tr><td>perspective、smooth_camera</td><td>切换视角、平滑相机</td></tr>
    <tr><td>hotbar_keys、inventory、swap_hand、drop_item</td><td>快捷栏数字键、背包、副手交换、丢弃</td></tr>
    <tr><td>chat、social_interaction、advancement</td><td>聊天、社交界面、进度界面</td></tr>
  </tbody>
</table>
<p>模拟语法为 <code>ml:input simulate &lt;action&gt; &lt;ticks&gt;</code>，持续时间至少 1 tick。支持 <code>forward</code>、<code>backward</code>、<code>left</code>、<code>right</code>、<code>jump</code>、<code>sneak</code>、<code>sprinting</code>、<code>attack</code>、<code>use</code>、<code>drop</code>。</p>
<div type="important" data-type="admonition" data-admo-type="important">
  <div data-type="admonition-title">全部锁定的恢复方式</div>
  <div data-type="admonition-content"><p>锁住 all 也会锁聊天，不能依赖玩家自己输入解锁指令。先在命令方块、服务端控制台或 <a href="?file=&quot;计划任务&quot;">计划任务</a> 中准备 <code>execute as @a run ml:input lock all false</code>。如果还单独添加过其他锁，也要逐项解除。</p></div>
</div>
<h2 id="隐藏-hud" data-toc-id="隐藏-hud">隐藏 HUD</h2>
<pre language="plaintext" isclosed="false"><code class="language-plaintext">/ml:hud crosshair true
/ml:hud hotbar true
/ml:hud crosshair false
/ml:hud hotbar false</code></pre>
<p>语法为 <code>ml:hud &lt;layer&gt; &lt;true|false&gt;</code>。图层支持 <code>all</code>、<code>hotbar</code>、<code>crosshair</code>、<code>health</code>、<code>armor</code>、<code>food</code>、<code>air</code>、<code>experience</code>、<code>chat</code>、<code>tab_list</code>、<code>effects</code>、<code>boss_bar</code>、<code>scoreboard</code>、<code>item_name</code>。<code>true</code> 隐藏，<code>false</code> 恢复该项；解除 <code>all</code> 后，之前单独隐藏的图层仍需分别恢复。</p>
<h2 id="指定玩家可见的实体发光" data-toc-id="指定玩家可见的实体发光">指定玩家可见的实体发光</h2>
<pre language="plaintext" isclosed="false"><code class="language-plaintext">/ml:glow_entity @s @e[tag=maplib_target] true 40FF70
/ml:glow_entity @s @e[tag=maplib_target] false
/ml:glow_entity @s</code></pre>
<p>语法为 <code>ml:glow_entity &lt;观察玩家&gt; &lt;实体&gt; &lt;是否发光&gt; [RGB颜色]</code>。颜色使用六位十六进制，可带 <code>#</code>，省略时为白色。只对指定观察者显示，不会让所有玩家都看到相同提示。只填写观察玩家时清除该玩家的 MapLib 发光设置。示例需先给目标实体添加 <code>maplib_target</code> 标签。</p>
