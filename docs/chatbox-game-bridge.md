# ChatBox 网页编辑器与本机游戏连接

连接入口在 `/chatbox/visual` 顶栏。游戏端实现位于 ChatBox 模组，不依赖 ViScriptLib，也不涉及旧的 `chatbox`、`chatbox2` 网页生成器。

## 使用

1. 安装包含桥接功能的 ChatBox 模组，在 Minecraft 1.21.1 / NeoForge 21.1 中进入世界，玩家需要由服务端确认拥有 4 级权限。
2. 在游戏中输入 `/chatbox editor start`。按 `T` 打开聊天栏，点击蓝色连接地址可复制完整地址，点击配对码可复制配对码；分别粘贴到网页「连接游戏」窗口中的「本机连接地址」和「配对码」输入框，再点击「连接游戏」。端口由游戏动态分配，请使用本次显示的完整地址。
3. 网页 ChatBox 编辑器点击“连接游戏”，输入上述两项。浏览器若询问本地网络权限，允许当前网站连接本机。
4. 连接成功后，左侧「游戏文件」显示与游戏指令补全一致的对话和主题。选择文件即可读取；右侧编辑后按 Ctrl+S / ⌘S 保存到服务端并重载。点击“游戏内预览”发送当前编辑内容；对话从选中句开始，没有选中句时从当前组第一句开始。
5. Esc、网页停止按钮、断开网页连接都会结束临时预览。`/chatbox editor stop` 会同时关闭本机监听服务。

网页编辑器需要保持与运行中的游戏连接。对话文件使用编辑器独立的固定测试界面，不继承当前游戏对话的界面，也不需要选择预览主题；文件引用的主题仅提供立绘和预设动画。主题文件自动使用示例文本，无需准备对话文件。未连接时显示连接提示，断线后保留当前编辑内容，重新连接后才能读取与保存。

## 数据和资源

- 翻译键来自游戏当前实际生效的语言表，包含模组、资源包和语言回退结果。本地新增翻译保留导入和编辑能力，作为预览草稿覆盖；不会改写游戏语言文件。
- 物品、方块、效果、属性、实体、附魔、生物群系、音效、粒子、流体及对应标签补全只读取当前连接游戏提供的注册表数据，包含当前模组与数据包条目。附魔、生物群系等依赖世界的数据在进入世界后提供。未连接或断开连接时补全为空，仍可手动输入 ID，不回退到网站静态清单。
- 已删除原有静态注册表 JavaScript 文件及物品、效果缩略图库。首页用到的六张装饰图片移至 `textures/home`，与编辑器数据分开；模组图标和作者头像保留。
- 资源面板只枚举客户端已启用的本地资源包（`resourcepacks` 中的目录或 ZIP）的 PNG/JPEG 贴图，不遍历原版、模组内置包或服务器下发包。只列出最终生效的贴图，显示来源，遵循游戏当前资源包覆盖与过滤规则。
- 贴图字段补全客户端已启用本地资源包中的图片，同时允许自由填写资源 ID，不要求 ID 出现在资源面板中。模组内置贴图仍可直接填写，例如 `chatbox:textures/gui/dialogue.png`；游戏预览按实际资源加载顺序解析。
- 物品缩略图由游戏按 GUI 显示方式离屏渲染，支持 CustomModelData。图片按需请求、缓存，不一次传输整套资源包。
- 已删除网页数据包与资源包导入、本地目录扫描和本地文件保存。文件列表与资源面板统一从游戏读取；图片按需从游戏获取，预览不再上传本地图片。
- 导出 JSON 保留资源 ID，不写入图片 Base64 或网页 Blob URL。

资源面板图片是静态缩略图；主题中央预览使用游戏实时渲染帧，包含该游戏实际渲染出的动态效果。

## 游戏文件与权限

连接后不需要导入数据包或资源包。文件 ID 来自服务端 ChatBox 加载器，读取最终生效的资源内容，覆盖顺序与游戏一致。网页显示来源及实际保存路径。

- 普通可写的世界数据包目录：直接保存到原 JSON。
- 模组 JAR、ZIP 或其他不可直接写入的来源：保存到当前世界的 `datapacks/chatbox_editor/data/<命名空间>/chatbox/…`，作为最高优先级覆盖数据包，不修改模组 JAR。
- 已存在的目标文件保留 `.json.bak`；保存成功后重载数据包。若重载失败则尝试恢复文件，并报告错误。
- 每次读取返回版本哈希；内容或来源变化后，旧版本保存会被拒绝，需重新读取。断线保留编辑内容；切换世界后不能把旧缓冲区保存到新世界。

`/chatbox editor start` 通过游戏网络向服务端鉴权，成功后才启动本机 WebSocket。列出、读取、保存请求均由服务端依据实际发包玩家重新检查 `hasPermission(4)`，不采用网页自报的权限。客户端定期复查权限，降级或离开世界会关闭桥接。服务端也必须安装支持此协议的 ChatBox 版本。

操作范围仅限已加载清单中的对话和主题；不提供任意文件读写、创建或删除接口。路径拒绝越界与符号链接；单个 JSON 上限 1 MiB，游戏网络按有序小块传输。

## 协议 v1

服务只绑定 `127.0.0.1`，入口 `/chatbox-editor`。每次启动服务生成新的随机配对码，一次允许一个已配对编辑器，配对码不存入浏览器持久存储。

客户端请求示例：

```json
{"id":"1","type":"hello","protocol":1,"token":"游戏显示的配对码"}
```

成功响应为 `{"id":"1","ok":true,"data":{}}`，失败响应为 `{"id":"1","ok":false,"error":"错误信息"}`。请求以字符串 ID 关联响应，允许乱序完成。

| 请求 | 参数 / 用途 |
| --- | --- |
| `hello` | `protocol`, `token`；配对后才能访问数据 |
| `ping` | 连接探测 |
| `snapshot` | 当前语言、翻译表、注册表、客户端本地资源包贴图索引、已加载主题、世界状态 |
| `image` | `kind: item/texture`, `resourceId`, 可选 `customModelData` |
| `asset.upload` | `resourceId`, `base64`；只接受临时贴图资源 |
| `assets.commit` | `images: string[]`, `translations: {语言代码:{键:译文}}`；提交本次预览资源清单 |
| `preview` | `kind: dialogue/theme`, `content`, 可选 `theme`, `group`, `index`, `stream`, `revision`, `sample` |
| `preview.stop` | 恢复预览前的对话状态 |
| `debug.start` | `session`, `version: 1`, `resourceId`, `content`, `group`, `index`；从指定节点运行当前草稿，执行正式游戏事件 |
| `debug.update` | 同一 `session`、`resourceId`，递增 `version` 和完整 `content`；更新当前玩家的调试草稿 |
| `debug.stop` | `session`；只结束匹配的调试会话并恢复客户端状态 |
| `files.list` | 返回加载清单、来源、保存位置和 `serverSession` |
| `files.read` | `kind: dialogue/theme`, `resourceId`, `serverSession`；返回 `content` 和 `revision` |
| `files.write` | 同上，加 `content`, `revision`；写入、重载后返回新来源和版本 |

服务事件使用 `event` 字段：`invalidate` 提示重新同步游戏数据；`preview.closed`、`preview.error` 同步预览结束或错误；`preview.frame` 携带 revision、sequence、PNG、画面与 GUI 尺寸和组件坐标。

预览过滤指令、脚本及其他非可视事件，不发送对话进度或点击动作到服务端。正式游戏对话或同步数据到来时，先结束临时预览。消息上限 16 MiB；单张上传图片上限 8 MiB、4096×4096；临时图片合计上限 64 MiB。

桥接已适配 ChatBox 1.1.5 的客户端类路径和对话生命周期，按 NeoForge 21.1.228 构建。临时预览支持新版 `bgm`、`stayTick` 和组件锁定状态事件；退出时停止预览 BGM 并恢复原对话状态。MVEL 事件及带表达式条件的事件在临时预览中不执行，文本中的 MVEL 占位表达式保留原文；这些字段仍会保留在项目导出的文件中。

网页主题事件已开放新版支持的条件、指令和 MVEL 类型，导入再导出时保留 `condition`，供正式游戏对话使用。

```sh

```


## 浏览器中的真实主题预览

打开主题文件后，网页自动发送当前草稿和示例名字、文本、选项；不需要额外对话文件。MC 使用临时 ChatBoxScreen 渲染主题，客户端在 RenderFrameEvent.Post 读取实际主帧缓冲，后台编码 PNG，通过已有鉴权 WebSocket 推送 `preview.frame`。浏览器显示这些帧，组件点击区域来自同一帧的游戏坐标。

- 最高 8 帧/秒，保持游戏窗口比例，输出上限 1600×900，GUI 尺寸随游戏窗口。编码或发送繁忙时跳帧，不排队积压。
- 每次草稿都有独立 revision；编码任务失效后不发送，浏览器拒绝旧版本或重复帧，图片解码完成后同时更新画面与点击区域。
- 右侧参数、层级临时隐藏和动画重播在 220ms 防抖后更新预览。画布拖动时，浏览器即时显示落点框及原位置虚线，通过 `preview.move` 持续同步坐标；同时最多一个移动请求，不积压鼠标轨迹，松手后完整同步最终主题。拖动组件临时保持当前动画姿势，松手后恢复主题动画；其他组件不重建。草稿不会写入数据包，仍需显式保存。
- MC 窗口保持打开并用于渲染，临时关闭失焦暂停。结束、断连、离开世界或权限失效时恢复原游戏对话状态及失焦暂停设置。Esc 可结束预览。
- 网页工具栏的游戏内预览仍可开启交互式对话测试；主题画面上的重新开始预览会恢复自动画面回传。
- 编辑器测试屏幕同时显示功能按钮和已启用的按键提示，不受正式对话 screen/render 模式的显示限制。按键提示的开关、位置和真实文字尺寸参与画布选中及拖动，正式游戏模式的规则保持不变。
- 正式 ChatBox 选项按 `originY + renderIndex * height` 连续排列，没有独立间距。主题预览遵循这一规则；固定的对话测试样式将选项缩至每项槽位的 90%，在相邻选项间留出空隙。
- 预览仍移除指令、脚本、带条件的执行事件和视频。它验证真实视觉渲染，不执行项目的服务端逻辑。

资源图片点击使用项目 Image 组件放大，单独的复制图片路径按钮在剪贴板写入成功后显示勾选及成功通知。图片类字段（立绘、悬浮/锁定贴图、附件、按钮、对话框、选项、按键提示、关键帧和对话背景）均补全同一份已启用本地资源包索引，仍允许手动输入未列出的模组资源 ID。

## 对话流程图

打开对话文件后默认显示组级主图，顶部可切回原来的列表。主图汇总组内所有对话的跨组跳转；同一对组的多处跳转显示次数，点击连线后选择具体来源，右侧定位到原始选项、事件或指令。双击组卡片或点击「进入组内」，可查看每句对话、组内推进、外部入口和跨组出口。

从节点右侧连接点拖到另一个节点的左侧，会直接创建文本为「继续」的选项。主图写入来源组最后一句的 `options[].next`；子图可从任一句创建选项，连接组内对话时写入从 0 开始的序号，连接其他组时写入组名并从第 0 句开始。已有选项不会被覆盖。空组需要先添加对话；数字和 `this` 是选项跳转的保留值，不能作为拖线创建的组名目标。

- 选项连线可在来源面板中改目标，也可拖动单条选项连线的目标端；「取消跳转」将 `next` 改为 `this`，保留选项文本和点击事件。
- 普通顺序推进只作显示，不新增 JSON 字段。事件和指令连线显示为可能跳转，条件是否满足仍由游戏判断。主题事件只读展示其来源和内容，不混入对话文件保存。
- 支持选项 `next`、`JUMP`、`GOTO_NEXT`、`chatbox skip` 和 `chatbox command nextDialogue`，并识别 `execute ... run`、引号组名及游戏按分号拆分的指令。MVEL 保留原样，不分析其中的跳转；动态指令和无法读取的主题会提示分析范围不完整。
- 当前只编辑同文件剧情。可静态确定的跨文件跳转、缺失或空目标组会拦截保存（按钮和快捷键共用校验），草稿保留。越界序号遵循游戏逻辑，显示为结束对话。
- 重命名同步修改可确定的当前文件组名引用。列表调整对话顺序时更新静态序号引用；无法安全更新的引用会阻止操作，涉及动态脚本或未读取主题时先提示检查。
- 选中节点或连线后按 `Delete` / `Backspace`，也可使用顶部删除按钮或节点右键菜单。普通对话节点删除数组中对应的一句；组节点确认后删除整组。其他句子指向被删句子的静态引用会阻止删除，需先修改这些跳转；被删句子自身的跳转不会阻止删除。
- 跨文件、缺失目标、跨组出口和外部入口都是跳转来源的投影，删除它们只清理对应跳转，不删除实际目标组。选项将 `next` 改为 `this`，保留文本和点击行为；直接跳转事件移除该事件；指令按游戏的分号规则仅移除对应跳转段，保留同字段其他指令。删除跳转条件中的最后一条命令时，同时移除对应事件，避免使原动作变成无条件执行。
- 同一目标节点关联的多处来源会一起清理；选中连线的具体来源可只删其中一处。主题只读来源和游戏默认顺序推进不能从对话图删除，操作会提示并保持整批来源不变。快捷键仅在流程图区域生效，输入框中的删除键继续正常编辑文字。
- 节点位置、缩放和平移仅在编辑器会话中保存，不写进游戏 JSON。可使用自动布局、适应画布、缩放按钮及小地图导航。

流程图的连线与布局不新增对话 JSON 字段。初版在 2026-10-19 的独立 Minecraft 1.21.1 / NeoForge 21.1.228 客户端中验证，使用浏览器实际拖线生成的 JSON，通过了新选项跳组、原有分支、循环和组内中途事件跳组的 5 项断言。临时 LDLib2 2.2.42 测试接入已移除。

## 对话交互调试

节点画布的滚轮直接缩放，按住空白处拖动平移。在对话文件中，右键组卡片、左侧组名或组内对话节点，选择「跳转对话」：组从第 0 句开始，对话节点从对应句开始，使用网页当前尚未保存的草稿和该文件引用的主题。

该入口运行正式的 ChatBox 交互链路，执行进入指令、选项、渲染事件及 MVEL；游戏中照常点击选项、推进对话。原「游戏内预览」仍用于过滤指令与脚本的视觉预览。两者互斥，调试需要支持 `dialogueDebug` 能力的新版模组及服务端 4 级权限。

- 网页实心播放标记和外框表示游戏实际所在组或对话；加粗连线和虚线节点表示静态分析得到的可能出口，条件由游戏判断，MVEL 中的动态跳转不作预测。位置从游戏成功进入节点后回传，支持普通推进、选项以及指令/事件导致的跳转。
- 「跟随游戏」自动将当前节点移到视野中；在子图中会跟随切换组，同时保留右侧正在编辑的对象。「定位当前对话」可主动回到当前句。「运行路径」保留最近 50 个位置，用于检查分支和循环。
- 修改名字、对话正文及数量不变的选项文字/提示，180ms 合并发送后直接替换当前画面的文字，不重新进入对话，不重放进入指令、声音或开始事件。其他参数在下一次进入该句后生效；删除运行中的句子会结束调试，需要重新跳转。
- 工具栏显示待同步、同步中、已同步或错误。无效静态跳转不会替换游戏中的有效草稿，修复后自动同步，也可点击重试。
- 草稿同时保存在当前客户端和服务端当前玩家的临时会话中，不替换全服加载数据，不向队伍其他玩家传播调试进度。调试执行的指令和脚本仍可能改变世界；结束调试只恢复客户端界面及原对话内容，不撤销游戏逻辑造成的变化。
- 调试不会自动写入文件，仍需 Ctrl+S / ⌘S 保存。结束、断线、离开编辑器或切换文件会释放调试会话；数据重载也会先结束调试。服务端检查每次调试请求的 4 级权限，并在执行调试动作时检查权限和连接租期。

`debug.state` 事件包含 `session`、递增 `sequence`、草稿 `version`、`resourceId`、`group` 和从 0 开始的 `index`。网页拒绝旧会话或乱序位置消息；`debug.closed`、`debug.error` 结束对应会话。跨文件运行时会显示实际文件 ID 并提示当前图仅展示本文件，不将其他文件位置误标为本文件节点。
